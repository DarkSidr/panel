# 3x-ui + nginx для Debian 13

Установка панели 3x-ui, HTTPS, подписок и firewall одной командой.
По умолчанию создаются семь готовых подключений с клиентами.
Новые VLESS-входы также автоматически настраиваются после сохранения в панели.

## Требования

- Чистый Debian 13 или Debian 12 с обновлением до 13, amd64 или arm64, доступ root.
- Два разных домена: для сайта и панели. Все A должны указывать на IPv4 VPS;
  AAAA-записи перед установкой нужно удалить.
- Открытые TCP 80, 443, 8443, 8444 и UDP 443; DNS без CDN proxy.
  Установщик открывает порты в своём firewall; внешний firewall провайдера настраивается отдельно.

Существующие nginx, 3x-ui и сторонние firewall-конфигурации не перезаписываются.

## Установка

Подставьте свои домены и почту, выполните на VPS от root:

```sh
curl -fL https://raw.githubusercontent.com/DarkSidr/panel/main/install.sh -o /tmp/proxy-install.sh
sh /tmp/proxy-install.sh install --site example.org --panel panel.example.org --email admin@example.org
```

Загрузчик скачивает исходники с GitHub; git на сервере не нужен.
Параметр `--email` необязателен. Перед сообщением об успешной установке проверяются
службы, firewall, работа Xray и HTTPS сайта и панели.
IPv6 на хосте отключается автоматически для текущих и будущих интерфейсов.
Настройки сохраняются в `/etc/sysctl.d/99-proxy-stack-ipv4.conf` и повторно
применяются службой `proxy-stack-ipv4.service` после настройки сети при загрузке.
nginx использует только IPv4. Удаление панели не включает IPv6 обратно.

Адрес панели, логин и пароль:

```sh
cat /etc/proxy-stack/credentials
```

На корне обоих доменов открывается сайт-заглушка.
Для входа в панель открывайте полный `URL` из этого файла, включая случайный путь.
После входа включите 2FA в настройках панели.

## Готовые подключения

| Подключение | Публичный порт по умолчанию |
|---|---|
| VLESS XHTTP + REALITY | TCP 443 |
| VLESS TCP + REALITY / Vision | TCP 8443 |
| VLESS gRPC + REALITY | TCP 8444 |
| VLESS XHTTP + TLS | TCP 443 |
| VLESS WebSocket + TLS | TCP 443 |
| Trojan WebSocket + TLS | TCP 443 |
| AmneziaWG 3.1 | UDP 443 |

У каждого входа есть включённый клиент без лимита трафика и срока действия,
собственная подписка и новые секреты. Ссылки доступны в панели и в root-only
`/etc/proxy-stack/default-subscriptions`. Для AWG автоматически создаётся публичный Host;
профиль скачивается из панели/подписки для клиента с поддержкой AWG 3.1.
Если порты REALITY заняты, выбираются свободные; дополнительные `--reality-name`
позволяют использовать TCP 443 с разными SNI.

Начните с XHTTP + REALITY; остальные варианты служат резервом для других сетей
и приложений. Работа у всех операторов России не гарантируется: блокировка IP,
UDP или разрешительный список может затронуть несколько вариантов сразу.
Обоснование выбора и источники: [исследование](docs/RESEARCH.md).

`--no-default-inbounds` устанавливает пустую панель.
`--manual-inbounds` отключает последующую автонастройку новых VLESS-входов;
создание первоначального набора управляется отдельно.
Для добавления набора в существующую установку этого проекта:

```sh
python3 /opt/proxy-stack/proxyctl.py seed-inbounds
```

Повторный запуск не создаёт дубликаты и не меняет ключи.

## Обновление Debian

На Debian 12 установщик предложит автоматическое обновление до Debian 13.
После согласия отдельная служба сохранит `/etc`, базу dpkg и список пакетов,
обновит систему, перезагрузит VPS и продолжит установку с теми же аргументами.
До согласия сделайте снимок VPS у провайдера: локальная копия конфигурации
не заменяет снимок диска и не позволяет откатить пакеты целиком.

Для запуска без интерактивного вопроса добавьте `--upgrade-debian`.
Журнал до/после перезагрузки: `journalctl -fu proxy-stack-upgrade.service`
и `journalctl -fu proxy-stack-resume.service`. Состояние и резервная копия:
`/var/lib/proxy-stack-upgrade/`. При ошибке обновление останавливается;
автоматического отката пакетов нет. После исправления ошибки установки
можно повторно запустить `systemctl start proxy-stack-resume.service`;
частично созданную панель сначала удалите штатной командой `uninstall`.
Копия обновления ОС хранится отдельно и сохраняется даже после `purge` панели.

Автообновление допускается только для Debian 12 с официальными репозиториями
bookworm, без backports, сторонних источников и удержанных/недонастроенных пакетов.
Debian 11 и старше нужно сначала обновить до 12; Ubuntu и другие дистрибутивы
не конвертируются в Debian, более новые Debian не понижаются до 13.

## Добавление подключений

1. Создайте VLESS-вход и клиента в панели, выберите транспорт.
2. Сохраните и дождитесь синхронизации — до 15 секунд.
3. Обновите страницу, затем скопируйте ссылку или подписку клиента.

RAW/TCP, XHTTP и gRPC получают REALITY; WebSocket и HTTPUpgrade — TLS через nginx.
Если TCP 443 уже занят другим REALITY-входом, автоматически выбирается дополнительный
публичный порт. Учётные данные и квоты клиентов сохраняются.

Для XHTTP/gRPC с обычным TLS добавьте `[TLS]` в примечание до первого сохранения.
Пометка `[MANUAL]` отключает автонастройку нового входа.
Дополнительные входы других протоколов и AWG настраиваются по [инструкции](docs/INBOUNDS.md).

## Обслуживание

```sh
python3 /opt/proxy-stack/proxyctl.py doctor
python3 /opt/proxy-stack/proxyctl.py status
python3 /opt/proxy-stack/proxyctl.py backup
python3 /opt/proxy-stack/proxyctl.py update
```

Обновляйте панель через `proxyctl.py update`: команда сохраняет резервную копию.

Если настройки входа не применились:

```sh
python3 /opt/proxy-stack/proxyctl.py sync
journalctl -u proxy-stack-sync.service -n 30
```

Дополнительно: [входы и подписки](docs/INBOUNDS.md),
[проверки](docs/VALIDATION.md), [безопасность](docs/SECURITY.md).

## Удаление

```sh
python3 /opt/proxy-stack/proxyctl.py uninstall
```

Резервные копии остаются в `/var/lib/proxy-stack`.
Для удаления вместе с резервными копиями и секретами используйте `purge` вместо `uninstall`.
