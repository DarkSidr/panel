# Проверки

## Локальные тесты

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
sh -n install.sh build.sh
```

Тесты проверяют маршруты nginx/firewall, автонастройку входов, сохранение данных
клиентов, обнаружение конкурентных изменений и загрузку установочного архива.
Они не заменяют проверку реального подключения.

Установщик и команда `doctor` проверяют службы, firewall, состояние и конфигурацию
Xray, а также HTTPS сайта и страницы входа с проверкой сертификата.

## На установленном сервере

```sh
python3 /opt/proxy-stack/proxyctl.py doctor
python3 /opt/proxy-stack/proxyctl.py status
nginx -t
systemctl --failed
certbot renew --dry-run
```

Проверьте HTTPS сайта и страницы входа, авторизацию панели и персональные подписки.
Для существующего REALITY-профиля доступна проверка полного подключения:

```sh
python3 /opt/proxy-stack/tests/profile_check.py --inbound 1
```

Укажите ID своего входа. Скрипт использует существующего клиента, не выводит его
ключи и не создаёт объекты в панели. Поддержка конкретного приложения и работа
из сети устройства проверяются отдельно.

Технические отчёты с адресами серверов, именами доменов и данными клиентов
не публикуются в репозитории.
