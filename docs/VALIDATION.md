# Проверки

## Локальные тесты

```sh
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
sh -n install.sh build.sh
```

Тесты проверяют маршруты nginx/firewall, автонастройку входов, сохранение данных
клиентов, первоначальные семь подключений, повтор после обрыва API без дубликатов,
этапы обновления Debian, обнаружение конкурентных изменений и загрузку установочного архива.
Они не заменяют проверку реального подключения.

Для проверки на настоящем релизе 3x-ui без изменения установленной панели:

```sh
python3 tests/defaults_smoke.py /path/to/extracted/x-ui/x-ui
```

Тест запускает отдельную панель с временной БД и loopback-портами, создаёт все
семь входов, повторяет операцию, читает и декодирует реальные подписки,
проверяет публичные адреса и поля AWG 3.1, удаление временного admin-токена
и фактический запуск Xray/AWG с проверкой конфигурации bundled Xray.
Проверен v3.11.0 на amd64.
Этот тест не проверяет прохождение трафика из сетей российских операторов
и не запускает обновление ОС. Debian 12 → 13 с перезагрузкой нужно дополнительно
проверять на отдельном тестовом VPS; боевой референс для этого не используется.

Установщик и команда `doctor` проверяют службы, firewall, состояние и конфигурацию
Xray, одинаковую заглушку на обоих доменах, страницу входа и HTTPS-маршрутизацию
с проверкой сертификата.

## На установленном сервере

```sh
python3 /opt/proxy-stack/proxyctl.py doctor
python3 /opt/proxy-stack/proxyctl.py status
nginx -t
systemctl --failed
certbot renew --dry-run
```

Проверьте HTTPS сайта и страницы входа, авторизацию панели и персональные подписки.
Для существующего REALITY-профиля доступна проверка полного подключения:

```sh
python3 /opt/proxy-stack/tests/profile_check.py --inbound 1
```

Укажите ID своего входа. Скрипт использует существующего клиента, не выводит его
ключи и не создаёт объекты в панели. Поддержка конкретного приложения и работа
из сети устройства проверяются отдельно.

Технические отчёты с адресами серверов, именами доменов и данными клиентов
не публикуются в репозитории.
